# USWDS skill

Build federal interfaces with the official [U.S. Web Design System Core](https://designsystem.digital.gov/).

Install:

```bash
npx skills add blencorp/skills --skill uswds
```

The skill covers official HTML components, Sass/CSS, JavaScript, tokens, utilities, layouts, patterns, theming, upgrades, and accessibility verification. It treats `@trussworks/react-uswds` as an optional community adapter rather than part of the official USWDS contract.

Current source and package observations live in [`references/sources.md`](references/sources.md), so changing versions remain separate from the concise skill instructions.

For agency-specific or state systems, start with the repository's [public-sector router](../public-sector-design-systems/).
